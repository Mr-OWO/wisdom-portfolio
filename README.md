## 🏛️ Portfolio Architecture

- **Frontend & Templates:** Clean, responsive multi-page architecture with dark terminal aesthetics, floating capsule navigation, and ambient glow effects.
- **24 Interactive Live Sandboxes:** Fully runnable client & server-side test benches across 4 categorized domains:
  1. **AI Systems & Alignment (4 Flagship Repos):** LLM-as-a-Judge Evaluation Framework, RL-Arena Platform (NestJS + React), Alignment Data Factory, and Agentic Code Execution Sandbox.
  2. **Full-Stack & Web Apps (4 Repos):** Real-Time Market Scraper, Binary Market Predictor, Social Trend Scout, and Fintech Settlement Debugger.
  3. **Backend, Cloud & SecOps (11 Repos):** Vulnerability Scanner, Phishing Threat Heuristics, Network Packet Inspector, IAM/RBAC Sandbox, Password Entropy Guard, Honeypot Telemetry, Secure Vault, Ransomware Guard, Asset Tracker, Config Auditor, and Patch Deployment Pipeline.
  4. **Customer Ops & Tooling (5 Repos):** AI-Powered Ticket Routing, Disaster Recovery Backup Validator, Keylogger Hook Detector, CSAT/NPS Analytics Radar, and Technical SOP Assistant.
- **Relational Data & Backend API:** SQLite relational database (`data/portfolio.db`) backed by FastAPI REST API and PHP cPanel proxy bridge.
- **Automated Deployment:** Continuous deployment pipeline to production cPanel environment at `wisdomowabor.online`.
